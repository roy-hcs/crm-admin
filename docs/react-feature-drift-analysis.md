## 1. 判定方法

1. 对 145 条 React 路由，取路由/页面文件的**首次提交日期**（`git log --diff-filter=A`）。
2. 建立路由 → 旧模板**文件级**映射（见
   `tmp/legacy_map.py`），避免把一个模板目录的变更误算到多个报表页。
3. 在旧仓库基准分支上取首提交之后、非 merge 的提交（`git log --no-merges --since=<首提交>`；2026-10-28 起 xbroker，历史行按 release——见头注「基线变更」）。
4. 人工排除非功能变更：样式、文案/i18n、静态资源版本号、依赖/渗透测试升级、纯后端修复、编码重构。
5. 覆盖判定以**当前 React 代码中是否存在该功能点**为准，不以「React 后续有提交」为准。React 有一批 2026-07-15 的批量重构提交（columnInfo/useMemo/console 清理），只代表重构，不代表功能同步。

结果：141 条路由有旧页面映射，其中 120 条在 React 首提交后旧页仍有提交；剔除样式/文案/后端修复后，确认
**59 项功能缺失（按功能点计，涉及约 36 个页面）**，另有 9 项需人工确认。其中 17 项已于 2026-10-28 补齐（出金风控 tab、代客入金、出金详情 IP 示警、出金详情账户活动 tab、出金详情取消订单、出金详情双重验证提示、出金详情订单 Timeline、出金详情右侧栏手机号、出金详情外部订单号、出金详情手动到账金额、出金详情出金记录通道列/筛选、出金详情入金记录通道列、入金详情外部订单号、入金审核角色筛选、入金审核邮箱/手机号筛选、杠杆详情组别/账号类型、开户审核备注上限），剩余 42 项；未实现项的原因与后端依赖见第 4 节。
